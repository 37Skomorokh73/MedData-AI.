# MedData-AI.

```markdown
# MedData AI: Мультимодальная система оценки риска развития сердечной недостаточности

Система поддержки принятия врачебных решений (СППВР) для раннего скрининга и детекции структурных патологий миокарда (предсердечная недостаточность, стадия B). Проект базируется на объединении биоэлектрических сигналов 12-канальной электрокардиографии (ЭКГ) и клинико-лабораторных показателей пациента на основе архитектуры позднего слияния данных (Late Fusion).

---

## 1. Суть проекта и клиническая актуальность

Сердечная недостаточность (СН) — прогрессирующий синдром с высокой летальностью. Критической проблемой современной кардиологии является выявление патологии на **субклинической стадии (Stage B)**, когда морфологические изменения миокарда (систолическая дисфункция левого желудочка, гипертрофия, клапанные нарушения) уже запущены, но явная симптоматика отсутствует.

Традиционный визуальный анализ 12-канальной ЭКГ врачом часто не позволяет уловить тонкие микроструктурные аномалии сигнала. В то же время стандартные клинические шкалы (Framingham, SCORE) обладают умеренной прогностической точностью. 

**MedData AI** решает эту задачу с помощью искусственного интеллекта:
1. Сигнал ЭКГ трансформируется в объективные цифровые биомаркеры с помощью глубоких сверточных сетей.
2. Цифровые признаки объединяются с гемодинамическими и биохимическими показателями пациента.
3. Мета-классификатор выполняет комплексную стратификацию риска с предоставлением интерпретируемого клинического обоснования.

---

## 2. Архитектура системы

Конвейер спроектирован по модульному принципу в парадигме **Late Fusion (позднего слияния)**:

```text
[ Сырая 12-канальная ЭКГ ]                   [ Клинические данные / СМАД ]
           │                                                │
     (Модуль 1: DSP)                                (Очистка и импутация)
Полосовой фильтр Баттерворта                        Нормализация признаков
  Z-нормализация отведений                                  │
           │                                                │
 (Модуль 2: Feature Extractor)                              │
 ResNet1d (EchoNext-Mini)                                   │
 Усеченный классификатор                                    │
           │                                                │
[ Вектор эмбеддингов: 256D ]                                │
           └───────────────────────┬────────────────────────┘
                                   ▼
                      (Модуль 3: Мета-модель)
                     XGBoost / CatBoost ансамбль
                                   │
                                   ▼
                   [ Оценка риска патологии (Stage B) ]

```

## 3. Проделанная исследовательская и инженерная работа (R&D)

В релизный репозиторий вошел лаконичный и оптимизированный пайплайн. Однако финальной сборке предшествовал масштабный цикл экспериментальных исследований («за скобками»):

### Этап 1: Цифровая обработка сигналов (DSP) и предобработка

* **Устранение шумов:** Реализован и протестирован полосовой фильтр Баттерворта 4-го порядка (полоса пропускания 0.5–40.0 Гц, zero-phase filtering через `scipy.signal.sosfiltfilt`), позволивший устранить низкочастотный дрейф изолинии от дыхания и высокочастотные сетевые наводки без искажения морфологии комплекса QRS.
* **Ресэмплинг:** Написан полифазный алгоритм ресэмплинга сигналов из частоты 500 Гц в целевой медицинский стандарт 250 Гц (размерность тензора 2500×12 для 10-секундной записи).
* **Контроль нормализации:** Проведены серии тестов по поотведенческой Z-нормализации. Были написаны специализированные скрипты визуализации для поканального сравнения сигналов до и после обработки, гарантирующие отсутствие искажений критических зубцов (P, R, T).
* **Изоляция данных:** Исключена проблема утечки данных (data leakage) — расчет параметров масштабирования зафиксирован строго внутри тренировочных выборок.

### Этап 2: Трансферное обучение и адаптация глубокой нейросети

* **Выбор основы:** Вместо обучения легковесной сети с нуля выбран подход Transfer Learning на базе архитектуры `ResNet1dWithTabular` (веса EchoNext-Mini, обученные исследователями Колумбийского университета на 100 000+ клинических записей).
* **«Хирургия» модели:** Классификационная голова нейросети отсечена и заменена на оператор `nn.Identity()`. Это позволило трансформировать сеть из жесткого бинарного классификатора в многомерный экстрактор признаков, генерирующий вектор плотных эмбеддингов ($\mathbb{R}^{256}$).
* **Синхронизация идентификаторов:** Отлажен и решен конфликт парсинга строковых и числовых ID записей (`ecg_XXXX` $\rightarrow$ чистый целочисленный `patient_id`), что обеспечило 100% сопоставление сигналов с диагностической разметкой `shd_moderate_or_greater_flag`.

### Этап 3: Мета-моделирование и валидация

* **Табличный классификатор:** Реализован конвейер градиентного бустинга `XGBoost`, принимающий на вход 256 извлеченных нейросетевых признаков.
* **Отказоустойчивость при малых выборках:** В код заложена динамическая проверка распределения классов: при запуске на демонстрационных микродатасетах алгоритм отключает стратификацию, предотвращая системные падения при единичных примерах классов.

### Этап 4: Аналитическое и регуляторное исследование (Документация)

* Проведен глубокий научно-технический обзор современных методов ИИ в кардиологии (EchoNext, ECG2HF, PULSE-HF, коммерческие СППВР от Eko Health и Biofourmis).
* Проанализированы регуляторные рамки для медицинского программного обеспечения как изделия (**SaMD**) по директивам EU MDR 2017/745 (Annex II) и FDA 510(k), включая требования к системе менеджмента рисков (ISO 14971) и предотвращению алгоритмической предвзятости.

## 6. Дорожная карта и дальнейшие планы развития

Проект находится в активной разработке. Следующие итерации включают:

1. **Мультимодальное слияние (Late Fusion 2.0):**
* Интеграция табличных биомаркеров крови (креатинин сыворотки, натрий, фракция выброса) из базы клинических записей.
* Подключение конвейера суточного мониторирования артериального давления (СМАД / ABPM Mendeley, база MUSIC) с расчетом гемодинамической нагрузки: суточный индекс (dipping status), вариабельность и пульсовое давление.


2. **Внедрение объяснимого искусственного интеллекта (Explainable AI — XAI):**
* **Для табличных данных:** Построение водопадных графиков `SHAP (TreeExplainer)` для количественной оценки вклада каждого клинического фактора в риск СН.
* **Для сигналов ЭКГ:** Интеграция библиотеки `Captum` (метод `Integrated Gradients`) для визуализации тепловых карт внимания поверх кардиограммы (подсветка элеваций ST, аберраций зубца T или уширения QRS).


3. **Расширенная клиническая валидация:**
* Расчет индексов чистой реклассификации **NRI (Net Reclassification Improvement)** и **IDI** для математического доказательства превосходства модели над стандартными клиническими шкалами.

## 7. Перспективы внедрения

Разрабатываемая СППВР ориентирована на применение в первичном звене здравоохранения:

* **Амбулаторный скрининг:** Автоматическая оценка риска СН при прохождении плановой диспансеризации на основе стандартной 10-секундной ЭКГ.
* **Триаж пациентов:** Раннее направление пациентов из группы высокого скрытого риска на углубленную эхокардиографию (ЭхоКГ) до развития необратимой декомпенсации миокарда.
* **Телемедицина:** Интеграция модуля в портативные кардиомониторы для дистанционного ведения пациентов кардиологического профиля.
